## Дүгнэлт

Fed-Ex, Supermodel аялал тус бүр таван согог илрүүлсэн бөгөөд Fed-Ex нь нэг номыг нэмэхээс устгах хүртэлх урсгалыг хамарснаараа хамгийн үр дүнтэй байв. Fed-Ex-ээр тоолуурын зөрүү, үсгийн том жижиг хэлбэрээс хамаарсан хайлт, устгалын мессеж, давхардал болон `&` тэмдэгт өөрчлөгдөхийг илрүүлэв. Supermodel-оор оны формат, устгах товчны өнгө, нэмэх товчны үсэг, урт гарчгийн байрлал, хуучин хувилбарын холбоосыг шалгав. Couch Potato аяллаар дутуу талбар болон хүчингүй оныг апп хадгалж байгааг ажиглав. Saboteur аяллаар синтаксийн алдаатай JSON-д API амжилтын статус буцааж байгааг баталгаажуулав.

Төлөвлөгөөнд тусгайлан заагаагүй `&` тэмдэгтийн асуудал номын гарчгийг нэмээд ижил утгаар нь хайх явцад илэрсэн. Дараагийн charter-д цэвэр төлвөөс гарын товчлуураар удирдах, дэлгэц уншигчийн шошго болон өөр браузер дахь харагдацыг шалгана. Лаб 1-ийн маягаар Playwright-д мөрийн тоо, хадгалагдсан өгөгдөл, хайлтын үр дүн, мэдэгдлийн текст, HTTP статусын шалгалт нэмбэл эдгээрийн зөрүүг автоматаар барина. Урт гарчгаас багана харагдахгүй болох болон ногоон устгах товч төөрөгдүүлэх эрсдэлийг дэлгэц дээр анзаарахад хялбар бөгөөд давтан автомат шалгалтад цонхны өргөн, өнгөний утгыг хэмжиж болно.

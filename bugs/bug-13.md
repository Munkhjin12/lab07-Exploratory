# BUG-13: Ном нэмэх API буруу JSON хүлээн аваад HTTP 200 буцааж байна

**Орчин:** Уншлагын жагсаалт v2.0 · Chrome 157.0.8103.79 · macOS 26.3.1 · Node.js v22.22.2 · curl 8.7.1 · 2026-11-21

**Урьдчилсан нөхцөл:** `node app.js` командаар аппыг шинээр асаана. Локал апп `http://localhost:3000` хаягт ажиллаж, анхны гурван номтой байна.

## Дахин гаргах алхам

1. Тусдаа терминалаас `curl -i http://localhost:3000/api/books` ажиллуулж, жагсаалтад гурван ном байгааг шалгана.
2. Төгсгөл дутуу JSON бүхий дараах хүсэлтийг локал апп руу илгээнэ.

   ```bash
   curl -i -X POST http://localhost:3000/api/books \
     -H 'Content-Type: application/json' \
     --data-binary '{'
   ```

3. Хариуны HTTP статус болон биеийг шалгана. Эхний GET хүсэлтийг давтаж, номын тоог харьцуулна.

**Хүлээгдэж байсан:** JSON-ийн бичлэг буруу тул API HTTP 400 буцааж, жагсаалтыг өөрчлөхгүй.

**Бодит үр дүн:** API `HTTP/1.1 200 OK` статус болон `{"result":"OK"}` бие буцаасан. Дараах GET хүсэлтээр анхны гурван ном хэвээр байгааг шалгасан.

**Ноцтой байдал:** Major. API ашиглаж буй клиент амжилттай хариу авсан тул ном хадгалагдсан гэж үзэх боломжтой.
